# ADR-007 (WP-00 draft): Un-bypassable scientific gate chain, claim ceiling, conservative failure

- Status: DRAFT (WP-00 baseline) — confirms adopted ADR-0005 + ADR-0007; constitution §2.3/§2.4
- Context: The product's value is truthful, traceable, non-over-claiming science
  (req spec §3.5–3.8, §13).
- Decision: Three frozen invariants, enforced in code and never relaxed by an
  implementation detail:
  1. **Gate chain**: real execution → checksummed Artifact → four-layer QC →
     evidence-admission gate (`validate_artifact_for_evidence`) → EvidenceItem →
     Claim → alignment audit. A missing link blocks the next.
  2. **Claim ceiling**: a claim level is `min(method capability, project ceiling)`;
     RNA DEG is capped at `association`. Enforced at claim synthesis and alignment
     audit. Only tightenable.
  3. **Conservative failure**: insufficiency/incompatibility/instability end in a
     legal terminal (INSUFFICIENT_DATA / METHOD_NOT_APPLICABLE / INCONCLUSIVE /
     CONFLICTING_EVIDENCE), never a fabricated result. Negative results are retained.
- Consequences: These are the constitution's R0-01 truthful-mode baseline; any WP
  that would weaken them is a BLOCKER requiring a CEO amendment.
- Cross-refs: adopted ADR-0005/0007; constitution §2.3/§2.4; req spec §13.13–13.15, §13.20.
- Open items: none — this is a frozen rail.
