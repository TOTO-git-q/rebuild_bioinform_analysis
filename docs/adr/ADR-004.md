# ADR-004 (WP-00 draft): Hexagonal ports with reserved production adapters

- Status: DRAFT (WP-00 baseline) — confirms adopted ADR-0004 + decisions D-03/D-05/D-06
- Context: Infrastructure (DB, object store, workflow engine, LLM, real data
  discovery) must be swappable without touching the domain core.
- Decision: The domain depends only on `Protocol` ports in `auto_bioinfo/ports/`:
  `PlannerPort`, `ResourceDiscoveryPort`, `AnalysisMethodPort`, `ObjectStorePort`,
  `EventStorePort`. Offline deterministic adapters are the defaults; production
  adapters (network LLM, GEO/Europe PMC discovery, S3/MinIO, Nextflow, PostgreSQL)
  are **RESERVED** and implement the same protocols. Dependency arrow stays inward
  (adapters → ports → domain).
- Consequences: Upgrading to production infra = add an adapter + inject it; core
  unchanged. Reserved adapters must not be silently treated as present capabilities
  (`docs/audit/method_asset_inventory.md`).
- Cross-refs: adopted ADR-0004; D-03/D-05/D-06; ADR-002/003/006/008.
- Open items: none blocking.
