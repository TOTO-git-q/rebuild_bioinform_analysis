# ADR-008 (WP-00 draft): LLM provider-agnostic; only public non-sensitive data leaves the boundary

- Status: DRAFT (WP-00 baseline) — confirms decision D-05 + constitution §5.6
- Context: Agents reason; tools own facts (req spec §3.3). An LLM must never write
  domain state directly, and restricted/sensitive data must never leave the local
  boundary.
- Decision: The LLM is a **provider-agnostic** reasoning adapter behind
  `PlannerPort`. Its output must pass the same schema + claim-ceiling validators as
  any other planner; it can propose but never commit facts (dataset IDs, file
  existence, run status come from tools). Only public, non-sensitive information may
  leave the boundary; patient/restricted data, secrets and internal credentials must
  not be sent to external models. Any external send is a hard stop requiring CEO
  authorization.
- Consequences: Today the default `OfflineDeterministicPlanner` needs no network.
  A network LLM adapter is reserved; enabling it touches a hard stop (constitution
  §4.5, baseline hard_stops).
- Cross-refs: D-05; constitution §5.6, §4.5; req spec §3.3, §8.1/§8.2; ADR-004.
- Open items: no formal secret-isolation layer yet (gap REQ-SEC-03); built in WP-23.
