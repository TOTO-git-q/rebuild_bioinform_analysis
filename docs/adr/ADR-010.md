# ADR-010 (WP-00 draft): Automation level A1, human approval gates, and ADR numbering coexistence

- Status: DRAFT (WP-00 baseline) — confirms decision D-04; records ADR bookkeeping
- Context: (1) The automation level and human-in-the-loop gates must be fixed.
  (2) The repo already has adopted ADRs `0001..0007`; this WP adds `ADR-001..010`.
  The two must coexist without contradiction or silent overwrite.
- Decision:
  1. **Automation A1** (D-04): mechanical steps run automatically; high-risk nodes —
     research spec confirmation, dataset locking / first real-data use, code changes,
     formal result export, public release — require human approval. A0–A3 gate policy
     evaluator + approval objects are built later (gap REQ-STG-10; plan WP-04/WP-13).
  2. **ADR numbering**: adopted `docs/adr/0001..0007` remain the authoritative,
     *accepted* records of the rebuild's realized decisions. `docs/adr/ADR-001..010`
     are WP-00 *baseline drafts* that frame D-01..D-06 and the plan architecture for
     the forward route. They cross-reference, never overwrite, the accepted set.
     Mapping below. A future consolidation (single numbering) is an open item for
     CEO/Codex, and does not block WP-00.
