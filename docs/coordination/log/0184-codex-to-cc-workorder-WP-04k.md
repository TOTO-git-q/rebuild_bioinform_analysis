## Authorized Scope

Build a pure local Python OpenAPI contract/spec layer over the existing control-plane contracts already merged through WP-04j.

Required behavior:

1. Define a bounded local OpenAPI 3.x-compatible spec representation for current local control-plane capabilities only. Cover only contracts already present in the codebase, such as project command/query, command API idempotency/concurrency, operation resource, CLI-facing command result shapes where relevant, and cancel command decision/result shapes.
2. The spec must be deterministic and generated or exposed from explicit local data structures. Prefer standard-library-compatible dict/list/string/number values and deterministic JSON serialization. Do not require third-party OpenAPI packages.
3. Every path, operation id, component schema, header, parameter, status category, and reason-code enum in the spec must bind to an existing local contract or a clearly bounded transport projection of that contract. Do not invent real server behavior, storage behavior, worker behavior, or permission behavior.
4. Include local transport-facing projections for idempotency key, expected-version/optimistic concurrency, operation status polling/result categories, and cancel-command request/decision outcomes where existing contracts support them. Keep projections deterministic and fail-closed for malformed internal facts.
5. Provide local validation helpers or tests that reject inconsistent specs: duplicate operation ids, component references to missing schemas, paths that point to unimplemented contracts, malformed status/reason-code enums, and accidental auth/security requirements before WP-04l.
6. Keep implementation pure and side-effect free in core logic: no file I/O, network, environment inspection, real clock, web server import, route registration, socket binding, subprocess, DB, queue/outbox, background worker, or external service call.
7. If adding a checked-in JSON fixture or docs-adjacent artifact, it must be repository-local, deterministic, generated by stdlib-compatible code, and not published/deployed. Do not create public hosted docs, release artifacts, package metadata, or automated publishing.
8. Preserve existing public Python APIs unless a tiny additive export is necessary for the OpenAPI contract. Do not refactor unrelated schema, state-machine, approval lifecycle, gate evaluator, query, method, evidence, report, execution, CLI, operation, or cancel modules beyond directly necessary additive mapping.
9. Add focused tests for deterministic spec generation, required path/component coverage, missing-reference rejection, duplicate operation-id rejection, bounded header/status/reason-code projection, no auth/RBAC before WP-04l, and no I/O/environment/network/clock/server side effects.
